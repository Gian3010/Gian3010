## 🤖 Projetos de IA
Os projetos abaixo usam **cenários e dados fictícios** (declarado nos READMEs). Testes e métricas de desempenho são medidos rodando o código; estimativas de impacto são simulações com premissas explícitas.

- **[LLM Prompt Lab](https://github.com/Gian3010/projeto-1-i.a)**: laboratório reprodutível que compara modelos e técnicas de prompt (zero-shot, few-shot, chain-of-thought) na extração estruturada de documentos de transporte. Avaliação por campo, taxonomia de erros (omissão, erro, alucinação) e baseline com regex. `Python` `Jupyter` `pytest`
- **[Ticket Triage Pipeline](https://github.com/Gian3010/Ticket-Triage-Pipeline)**: pipeline que lê tickets de suporte, mascara dados pessoais (LGPD), classifica com LLM com fallback por regras, calcula SLA e grava no PostgreSQL para dashboard. `Python` `PostgreSQL` `Docker` `SQLAlchemy`
- **[Copiloto de Dados](https://github.com/Gian3010/projeto-3-i.a)**: app Streamlit com agente de IA (tool use) que responde perguntas de negócio escrevendo SQL somente leitura, com travas de segurança, gráfico automático e log de auditoria. `Python` `Streamlit` `SQLite`
- **[Review Insight API](https://github.com/Gian3010/projeto-4-i.a)**: API FastAPI que classifica sentimento e tópico de avaliações em português, com autenticação, rate limit, métricas Prometheus, Docker, teste de carga e deploy no Render. `FastAPI` `scikit-learn` `Docker`
